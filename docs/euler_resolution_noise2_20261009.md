# Euler 64/50步：双噪声当前模型实测

固定在线第160轮checkpoint，SHA256 `062dde4773ec54231cc2381c06d6ff43a51f58ceab9996c57c2f14d4d06d17ee`。两份固定噪声、FP32、同一初态和记录动作，对照Euler100与Euler64/50。四种场景（online_ac、dta、random、congested）各连续滚动8个30秒窗口，在30/90/240秒评分。未来真实状态仅作标签，递归输入为样本0的预测状态；固定记录动作测试不是新策略闭环。

## 速度

8轨迹×2噪声=模型batch16，整模型编译。每个候选与100步交替计时三对，单次包括完整单窗口Euler积分。64步配对总时间加速1.176倍（耗时约减少15%），50步1.894倍（约减少47%）。64步组中位时间100/64分别2.770/2.183秒；50步组100/50分别5.266/2.735秒。GPU被其他作业共享，两组参考耗时明显变化，不可跨组直接比较绝对秒数，也不可将时间按比例作为完整想象+AC实测结果。

## 真实标签误差

240秒时，已有车辆路段速度MAE（m/s）：

| 场景 | Euler100 | Euler64 | Euler50 |
|---|---:|---:|---:|
| online_ac | 1.38194 | 1.31548 | 1.28197 |
| dta | 1.52363 | 1.53910 | 1.35071 |
| random | 1.18345 | 1.22131 | 1.24163 |
| congested | 0.98309 | 0.98057 | 0.96446 |

随机路由的慢路（4条）速度MAE分别5.74048/7.40882/8.08981m/s。该局部误差没有被全路平均所充分反映。100步本身仍有很大预测误差，但减少步数在这个场景进一步恶化；其他场景减少步数可能更接近标签，不能把数值偏离100步一概当作交通预测退化。

两种候选各12项数值检查中均仅1项同时通过既有工程阈值（样本0 latent相对L2≤1%，全局方差变化≤5%，单条慢路与参考速度差≤0.1m/s）。64/50步最坏latent差分别2.956%/4.466%，最坏单慢路差5.962/8.433m/s。稀疏DTA场景50步在240秒的全局方差为参考的5.065倍；该比值不直接代表风险惩罚绝对幅度或方差估计准确性。

结论：少步数能够显著加速，但当前证据不支持把主线直接切成64或50步。生产继续Euler100与双噪声，不改变在线训练或其checkpoint。后续如希望用50步，应针对少步数重新适配/蒸馏，并用真实慢路标签、滚动误差、disagreement和闭环策略验证，而非只优化对100步输出的拟合。
