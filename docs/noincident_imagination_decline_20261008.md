# 无事故主线：完成率跃升与后期想象更新退化

诊断源：outputs/noincident_decline_diagnosis_20261008/frozen/checkpoints/latest.pt，第493轮。所有实验均不修改生产状态。

## 真实曲线

全阶段51–100轮费用9.427分钟/车、完成率99.768%；401–450轮费用14.119分钟/车、完成率98.728%。两个100%到达的实际episode125和401，完整旅行时间8.503与12.010分钟。故后期费用增加不能由未完成车辆比例单独解释。

12个原始存档精确核验exposure恒等式；抽样早期改善约67%表现为完成比例变化、33%为条件均值变化，但是描述性代数分解，非同车辆因果贡献。已完成群体旅行时间也降低。后期抽样已完成车辆均值9.552→12.786分钟，非最短候选39.44%→42.94%，额外自由流费用289.63→397.50秒/车，位移下界4.44→5.43km，静止代理比例6.93%→9.29%。OD/出发分层后下降仍存在。

## 世界模型与尾部价值

现有4个真实存档、每个2起点、4个30秒转移回顾性检查：速度按训练的前向均值标签核对。初始到当前teacher-forced有车路段速度MAE1.318→1.121m/s，4步递归1.408→1.198；不能说世界模型整体越训越坏。Codec参数未变、误差相同。

残留局部偏差较大：episode485的315358255#0有46辆车，目标前向速度0.740m/s，teacher-forced模型预测32.59辆、4.713m/s；其他持续慢速队列也被预测为5–12m/s。这是正常拥堵，无事故。总体均值loss可能掩盖这些会严重影响路由的局部误差。

实际seed-cohort尾部费用的回顾性检查：episode485在1200秒活跃462辆，仅这些车辆到终点/时限的实际shared return为-7.066，V为-3.832，偏乐观3.235。此标签由既有行为产生，不直接作为当前策略Q训练标签，也没有输入想象优化。

想象最多240秒，V只有mean road latent+time/active fraction，没有显式各车目的地/剩余路线。个体超时只在rollout到真实3810秒期限才出现；更早种子通常看不到失败惩罚，V/Q又不含个体超时目标，尾部信用缺口不会自动被补回。

## 可确定结论与限制

早期主要学会完成；后期在接近全完成后继续增加绕行和等待。最强机制证据是：残留世界模型/尾部价值乐观偏差，加上不断优化自己生成的标签，能使真实随机策略恶化；低Q/V loss只证明拟合想象标签。Entropy尺度不一致会干扰优化，修复它不足以解决全部问题。基线因果detach/更新顺序未发现错误。

本诊断包含一个checkpoint、两组受控真实需求，不能确定所有原因的百分比或证明修复后收敛。后续修复验收须看配对真实随机策略的旅行时间与完成率；argmax正常或想象loss下降都不够。所有原始证明位于outputs/noincident_decline_diagnosis_20261008/{trajectory,world,value,entropy,credit}。
