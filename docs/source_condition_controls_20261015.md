# 粗预测条件与 FM 起点对照

旧实验的 B 已通过额外输入使用背景增量 `b(Z)`。因此，B/C2 只能检验在同样提供背景条件后，进一步移动起点和参考状态的收益，不能检验背景条件本身的必要性。

| 组别 | FM 起点 | 背景增量条件 | 参考状态 |
| --- | --- | --- | --- |
| G | `ε ~ N(0,I)`，全道路、全潜在维独立 | 无 | `Z` |
| A | `Z + 0.1 U16 ξ` | 无 | `Z` |
| B | `Z + 0.1 U16 ξ` | 有 `b(Z)` | `Z` |
| C2 | `Z + b(Z) + 0.1 U16 ξ` | 有 `b(Z)` | `Z+b(Z)` |

所有组保留当前状态与记录的动作/动作事件条件。“无条件”在本实验中明确指不提供粗预测条件，并非删除状态与动作。A/G 不执行背景预测，缓存中的 `b` 不影响其损失或梯度。

三个预先定义的比较：

- B 对 A：背景条件是否改善最终 FM 预测。
- A 对 G：整体起点分布选择的影响，同时改变均值与协方差，不能只解释成移动均值的效果。
- C2 对 B：背景已作为条件时，将它用于起点和参考状态是否进一步有益。

运行目录为 `outputs/source_condition_controls_20261015/v1`。A/G 从完整预训练检查点重新适配；B 从上一轮第 4 个 epoch 连同完整 AdamW 状态继续；C2 复用已完成验证平台停止的运行所选第 10 个 epoch 检查点。完整预训练检查点 SHA256 为 `2f63f0b2a5fe18f3a3bd9be27ffd1e63a2755464e7f2944e1227334f0ffe6af6`。

三组新训练沿用 64 个训练需求组、768 个窗口、四组分层时间/噪声抽样，共 3072 个全图训练样本。每批两张全图，仅更新最后一个 Transformer block、reference projection、原速度场输出头及直接条件残差头，共 1,414,528 个参数。前五层冻结权重，但保留到 reference projection 的梯度路径。没有新增 SUMO 交互。

G 重新生成全维独立单位高斯噪声，不能复用原 rank-16 噪声系数作为全图噪声。G 的相对生成状态输入仅用训练数据重估 RMS；A/B 沿用相同的原归一化。该预处理差异写入每组 `normalizers.json`。

每个 epoch 用相同的 8 个验证状态、4 个需求组、4 个样本和 100 步 Euler 积分测量 Energy Score，选择最低值。连续 5 次未改善至少 0.2% 后学习率乘 0.3；两次降学习率后再达到平台才停止。最多 80 个全局 epoch，若达到上限则标为预算受限，共同测试保持关闭。实际更新次数分别记录；这不是严格等更新预算的实验。

共同测试集预留 16 个此前实验未使用的需求组、32 个状态，等 A/G/B 均完成验证集选模后才评测。四个模型使用同一组条件，每条件 8 个样本，100 步 Euler 积分，报告 CRPS、Energy Score、覆盖率/区间宽度及点预测诊断，并按完整需求组配对 bootstrap。C2 的检查点在新测试划分前已经确定。

这是已有完整预训练骨干上的部分适配诊断。尤其 G 改变了冻结前缀所面对的输入分布，因此即使其结果较弱，也不能据此否定充分联合训练的普通高斯 FM。单个适配种子和离线预测结果也不能证明下游策略收益。

实现复用已有的预训练加载、轨迹采样、训练状态保存和验证平台规则，新增 `tools/source_condition_controls.py`、`tools/train_source_condition_control.py` 和 `tools/evaluate_source_condition_controls.py`。配套测试验证起点/参考状态/背景输入、实际六层 Dynamics 的完整 CFM 目标与梯度、全维高斯训练缓存及归一化，以及未完成选模时禁止打开共同测试集。相关 48 个测试通过。

运行目录内的 `postprocess` 保存冻结的评估与独立复算脚本，后台 watcher 等待三组完成选模后，依次核对训练记录、执行共同测试并独立复算指标和置信区间。进度见 `pipeline_progress.json`，成功后生成 `shared_test/summary.json`、`independent_training_audit.json`、`independent_test_audit.json` 与 `report.md`；出现预算上限或任务异常则停止流程并记录原因。训练及共同测试尚未完成时，不预设 prior 有效或无效。
